# A Small Sorry

A responsive animated apology page made with plain HTML, CSS, and JavaScript.

## Personalise the shared link

The page supports three optional URL parameters:

- `to` — recipient name
- `from` — sender name
- `reason` — what the apology is for

Example:

```text
https://YOUR-USERNAME.github.io/sorry-from-aayush/?to=Someone&from=Aayush&reason=what%20I%20said
```

All text is inserted safely as plain text in the browser. No response data is collected or sent anywhere.
